## 📖 Sobre o Repositório

Bem-vindo(a) ao **Java Essentials**! Este repositório foi criado para consolidar os principais conceitos da linguagem **Java**, utilizando recursos modernos e boas práticas. Cada pasta contém exemplos práticos, comentados e direto ao ponto, ideais tanto para quem está começando agora quanto para quem quer relembrar a sintaxe da linguagem.

---

## 🗂️ Conteúdo Programático

O repositório está dividido nos seguintes módulos fundamentais:

| Módulo | Descrição | Principais Conceitos |
| :--- | :--- | :--- |
| **01. Variáveis e Tipos** | Introdução aos tipos primitivos e manipulação básica. | `int`, `double`, `String`, `boolean`, operações aritméticas. |
| **02. Condicionais** | Tomada de decisão no código. | `if`, `else if`, `else`, `switch-case`. |
| **03. Laços de Repetição** | Automatizando tarefas repetitivas. | `for`, `while`, `do-while`, loops aninhados. |
| **04. Funções (Métodos)** | Modularização e reutilização de código. | Declaração, parâmetros, retorno, escopo. |
| **05. Arrays e Listas** | Estruturas para armazenamento de múltiplos dados. | Vetores unidimensionais/bidimensionais, `ArrayList`, métodos úteis. |
| **06. Orientação a Objetos** | Os pilares do paradigma orientado a objetos em Java. | Classes, Objetos, Construtores, Encapsulamento, Herança, Polimorfismo. |
